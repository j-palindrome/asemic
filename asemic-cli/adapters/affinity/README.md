# affinity adapter

Backend for the `affinity(id, input, file=None, **opts)` renderer row (`asemic_py/namespace.py`).

1. Row: starts the adapter (`asemic/adapter/affinity/start`, returns once ready), then puts `asemic/in/affinity/row/<id>` = `{input, file, opts, root}` — `id`/`input` block-relative, `root` = folder of the open file, `file` = optional file-relative path to the Affinity document (`.af`).
2. Document lifecycle: if `file` is specified, the adapter ensures the document exists (creating it from template if missing) and opens it in Affinity if not already open before rendering. If `file` is omitted, the adapter requires an existing document saved inside `root` to already be open.
3. Backend = Rust crate in the [crate/](crate/src/main.rs) subfolder (`asemic-affinity`): per row, each new multiarray on `asemic/gen/<input>` -> `score::document` -> drawn in Affinity; doc saved at `<root>/<id>.json`; page grab -> `asemic/preview/<id>`; log -> `asemic/out/affinity/<id>/log`.
4. `affinity.rs`: one MCP session to Affinity (Settings -> MCP Server, SSE :6767) via `rmcp` 0.10 (last with the SSE client; Affinity is SSE-only); runs `scripts/asemic-render.js`. Only a document saved inside `root` is drawn on.
5. `score.rs`: multiarray -> score/line ops (`cargo test -p asemic-affinity`); grid = the `x`/`y` pairs. `opts`: x ([bar, beat] quarter-note intervals: x[0] = the barline interval (heavy rule every x[0] quarters), 0 = unmeasured single row; x[1] = light rule every n quarters, 0 = off, fractions = grids e.g. 1/12 = the twelve-time grid; systems = settings.spacing bars, evenly spaced), y ([subdivisions/octave, accidentals/line-space]: [6,3] = normal staff, 5-line treble, accidental by the FOLLOWING note's motion (down = flat, up = sharp), no naturals | [6,1] = staff without accidentals | [1,1] = one rule per octave C | [12,1] = chromatic, 1 position per halfstep, 0 = middle C; the accidental count = the microtone ladder (quarter-/third-tones) — until glyphs exist, other pairs render nothing), notes (event layers, superimposed — tuple = exact set: heads (noteheads + ledgers) | stems | lines (headless dur bars, thickness = dynamics) | accidentals (motion-spelled glyph, flat moves the head, y[1] gate; without the layer heads just round to the nearest division) | names (pitch labels next to noteheads); `notes` = the heads+stems+accidentals preset (inside tuples too), string = `notes` or one layer, default = notes trio), names (note name format: 'pitchclass' [0..9, t, e], 'midi', 'hz', 'notename' [A5], 'note' [A]), settings (layout knobs: spacing = a kerning multiplier over the auto span — 1 = default, 0.5 = half-spacing = twice the quarters/system, 2 = half the span; the span rounds to the nearest barline, systems evenly spaced w/ the same quarter count, base = auto ~16-quarter systems: x[0]=4 fills 4 bars/system, x[0]=16 = 1), pitch, dur, vel, lo, hi, beats (dur-absent x gap -> beats scale).
